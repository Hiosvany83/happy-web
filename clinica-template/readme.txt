================================================================
VIDAPLENA — Medical Clinic HTML Template · v1.0
================================================================

A clean, fully responsive HTML5/CSS3/JS template for medical
clinics, doctor's offices, dental practices and health centres.
No frameworks, no build step, no external dependencies — it
works offline and on any static host.

PAGES
  index.html ......... Home (hero, services, why-us, testimonials)
  services.html ...... Services & prices with category tabs
  doctors.html ....... Doctors / team profiles (CSS initial avatars)
  about.html ......... Story, values, facilities preview
  facilities.html .... Facilities gallery with lightbox
  appointment.html ... Appointment form + contact info

FEATURES
  * Dark / light mode toggle (saved per visitor)
  * Mobile navigation + fully responsive layout
  * Scroll-reveal animations
  * Auto-rotating testimonials slider
  * Client-side form validation
  * Buyer documentation included (documentation.html)

QUICK START
  1. Unzip. 2. Upload the folder to your host (or open index.html).
  3. Replace the demo graphics in assets/img/ with your own photos
     and the fictional demo doctors with your real team.
  Full guide: documentation.html
