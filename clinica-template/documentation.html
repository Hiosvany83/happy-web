VidaPlena — Medical Clinic HTML Template

Documentation · Version 1.0 · Pure HTML5 / CSS3 / Vanilla JavaScript — no frameworks, no build step, no external dependencies.

2. Installation

  1. Unzip the package.
  2. Upload the whole vidaplena-clinic-template folder to your web host (or open index.html locally in a browser — everything works without a server).
  3. Done. There is no build step and nothing to compile.

Note: The appointment form validates on the client side and shows a confirmation message, but it does not send email or store bookings by itself. Connect it to your booking system or a form service by pointing the form's submit handler (see js/form.js) to your endpoint.

3. Customising

3.1 Colours & dark mode

All colours live in CSS variables at the top of css/style.css. Change --accent (clinical teal) and --accent2 (calm green) to rebrand the whole site. Dark-mode values are in the [data-theme="dark"] block right below. The toggle button in the header switches themes and remembers the visitor's choice in localStorage.

3.2 Text & content

Every text is plain HTML — edit it directly in the page files. The header, footer and navigation are repeated in each page (standard for static templates), so update them in all six files when you change links or contact details.

3.3 Clinic name & logo

The demo clinic is called VidaPlena. To rename it, search-and-replace VidaPlena and vidaplena across the HTML files (titles, logo, footer and the example email addresses), and swap the ✚ logo mark in the header/footer for your own symbol or an image.

3.4 Images

Demo graphics are in assets/img/. They are original abstract illustrations generated for this template. Replace them with your own photos using the same file names to avoid touching any HTML:

The facilities gallery also includes CSS “art tiles” — gradient placeholders with an icon and text. Replace a tile with a photo by swapping the .art-tile block for an <img> tag (example in the facilities page comments).

3.5 Doctors & team

Doctor profiles live in doctors.html as .team-card blocks. The avatars are CSS circles with the doctor's initials — a deliberate placeholder, so the template ships with no stock-photo faces. To use a real photo, replace the .avatar div with an <img class="avatar"> using your own staff photo. All demo names and bios are fictional placeholders: replace them with your real team before going live. Remember to also update the “Preferred doctor” list in appointment.html.

3.6 Services & prices

Service categories are panels in services.html. Each tab button has a data-target matching a panel id (panel-general, panel-specialists, panel-lab, panel-prevention). To add a category: copy a button, change its label and data-target, then copy a panel with the matching id and edit the services and prices.

3.7 Testimonials

Add or remove .testimonial-slide blocks in index.html — the slider dots and auto-rotation adjust automatically. Demo testimonials are fictional placeholders; use real patient quotes only with their consent.

3.8 Appointment form rules

Validation lives in js/form.js: required fields, email format, phone (7+ digits) and no past dates. Edit those rules in one place if your clinic differs. The department and doctor dropdowns are plain <select> elements in appointment.html — edit their options to match your clinic.

4. Browser support

Current versions of Chrome, Firefox, Safari and Edge. Uses CSS variables, flexbox, grid and IntersectionObserver — with graceful fallbacks (content stays visible if an API is missing).
